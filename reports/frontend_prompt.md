# Emergent.ai frontend prompt

Paste the block below into Emergent.ai. Start the backend first
(`uvicorn src.api:app --port 8000`) and expose it if Emergent needs a public URL
(e.g. `ngrok http 8000`), then replace `API_BASE`.

---

Build a single-page web app called **"AI Customer Support Agent — Spotify"**.

No authentication, no dashboard, no accounts, no database. One page.

**API**: `API_BASE = http://localhost:8000`

**Layout**

Header: title "AI Customer Support Agent", subtitle "Evidence-backed triage for @SpotifyCares".

Input card:
- A textarea, placeholder "Paste a customer tweet…", 3 rows.
- Four clickable example chips that fill the textarea:
  - "I was charged twice for premium this month, please refund"
  - "how do I make a playlist collaborative?"
  - "my downloaded songs won't play offline since the update"
  - "someone hacked my account and changed my email"
- A primary button **Analyze**. Show a spinner while loading. Ctrl+Enter also submits.

On click, POST to `${API_BASE}/predict` with `{"message": "<textarea>"}`.

**Results**

First, a full-width **decision banner** — the most prominent element on the page:
- If `decision === "AUTO-HANDLE"`: green background, ✓ icon, "AUTO-HANDLE — the agent can answer this".
- If `decision === "ESCALATE"`: amber/orange background, ⚠ icon, "ESCALATE — human review recommended".
- Under the heading, show `decision_reason` in full as plain sentence text. Never truncate it — it is the point of the product.

Then a row of four small stat cards:
1. **Intent** — `intent` (replace underscores with spaces), with `intent_runner_up` shown small underneath as "runner-up: …".
2. **Confidence** — `intent_confidence` as a percentage with a thin progress bar.
3. **Risk** — `risk_level`, colour-coded (LOW grey, MEDIUM amber, HIGH red).
4. **Evidence quality** — `evidence_quality` as a percentage with a progress bar.

Then a **Suggested reply** card:
- Show `reply` in a quoted/message style block with a Copy button.
- If `reply_is_suggestion_only` is true, add a small amber label above it: "Draft for human review — not sent automatically".
- Small footer line: "generated by: `generation_backend`".

Then **Historical evidence** — the trust feature, keep it visible and not collapsed by default:
- Heading "What this is based on (`evidence.length` past cases)".
- One card per item in `evidence`:
  - a similarity badge showing `similarity` as a percentage (green ≥40%, amber 20–40%, grey below)
  - **Customer said:** `customer_message`
  - **Spotify replied:** `historical_reply`
  - a small tag with `historical_intent`
  - if `is_boilerplate` is true, a grey tag "generic reply — weak evidence"

Finally a collapsed `<details>` section "Agent trace & signals" containing:
- `evidence_signals` as a small key/value table (values are 0–1, show as percentages)
- `evidence_flags` as red chips (nothing if empty)
- `critique.verdict` and `critique.issues`
- the `trace` array as an ordered list of `tool` names — this shows the agent's steps in order

**Style**: clean, light, lots of whitespace, rounded cards, subtle borders, system font stack. Spotify green (#1DB954) only as the accent for AUTO-HANDLE and primary buttons. Must be readable on mobile — cards stack vertically.

**Error handling**: if the request fails, show a red inline message "Backend unreachable — is uvicorn running on port 8000?". Do not use `alert()`.

Do not add: login, signup, user profiles, analytics charts, admin panels, dark-mode toggle, or a message history sidebar.
